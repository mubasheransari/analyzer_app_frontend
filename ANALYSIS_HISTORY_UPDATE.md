# Analysis History Update

Implemented in Flutter:
- Profile > Analysis History now opens a history screen.
- `My` and `Other` tabs separate the current user's analyses from other users' analyses.
- Every history item shows analyst, date, coin, trend, risk and target.
- Tapping an item opens the complete analysis.
- View PDF and Download PDF actions are available from the analysis detail sheet.
- Notifications are shown from the history screen, with unread badge and polling every 20 seconds.
- New API methods and models were added for history, notifications and PDFs.

Run `flutter pub get` after extracting the project.
